
# Software Requirement Specification (SRS)

# ThreatDragonX

Version: 1.0

Author: Ashish Kumar Giri

---

# 1. Introduction

ThreatDragonX is a web-based Threat Modeling application.

It allows software teams to create Data Flow Diagrams (DFD), identify security threats using STRIDE methodology, manage mitigations, and export professional reports.

---

# 2. Objective

Develop a modern Threat Modeling platform using

- Angular
- Node.js
- Express
- MongoDB
- TypeScript
